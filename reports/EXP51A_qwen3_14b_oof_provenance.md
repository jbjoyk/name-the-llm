## 1. Executive Summary

This forensic provenance audit was commissioned to verify whether the Qwen3-14B predictions evaluated in EXP51 (which achieved 0.6346 Balanced Accuracy and fused with EXP47 to reach 0.7873 BA) are **genuinely prompt-disjoint 5-fold out-of-fold predictions**, or whether they suffered from full-fit data leakage or prompt contamination.

### Core Findings:
1. **Prompt-Disjoint Out-Of-Fold Validity**: **CONFIRMED VALID**.
   The artifact was generated via strict 5-fold prompt-disjoint cross-validation. Every one of the 150 prompts in `train.csv` belongs to exactly one fold (30 prompts per fold). For every row $i$ in fold $k$, the model making the prediction was trained strictly on `fold != k` and never observed row $i$ or any other completion of row $i$'s prompt.
2. **Cryptographic Proof of Distinct Fold Adapters**:
   We downloaded and inspected `heads.pt` from `q14v5_f0`, `q14v5_f1`, `q14v5_f2`, and the full-fit `q14v5`. Each fold model possesses a **unique SHA-256 hash** and distinct parameter tensors (pairwise maximum absolute parameter difference $\approx 0.022$ across `plain.weight` $[18, 40960]$). This definitively disproves any hypothesis that the full-fit model was duplicated across folds.
3. **Exact Split Mechanism Identified**:
   The prompt fold assignment was generated by:
   ```python
   prompts = np.array(sorted(train.prompt_id.unique()))
   rng0 = np.random.RandomState(0)
   rng0.shuffle(prompts)
   fold = train.prompt_id.map({p: i % 5 for i, p in enumerate(prompts)}).values
   ```
   This formula was confirmed from the published training worker script ([`lucasboesen/name-that-llm-train-lora24-s7.ipynb`](file:///tmp/lucasboesen/name-that-llm-train-lora24-s7.ipynb)) and matches the artifact's `fold` column with **100.0% bitwise parity across all 2,699 rows**.
4. **Lineage Disambiguation**:
   - The artifact is **NOT** from Nishant Dahal's `two-stage-lora-part-two.ipynb` (`lora_qwen3_14b`, which scored 0.611 OOF BA and released only a single full-fit checkpoint).
   - The artifact is from **team Anto Pil / Dhruv Tibarewal's `q14v5`** (Qwen3-14B LoRA24 trained on 120k pool + train across 5 folds, scoring 0.6346 OOF BA, public LB 0.666/0.672).
5. **Partition Alignment vs EXP47 Baseline**:
   Our local EXP47 baseline used standard `sklearn.model_selection.GroupKFold(n_splits=5)` on `train.csv` file order, whereas Anto Pil used `RandomState(0).shuffle(prompts)`. Both partitions are 100% prompt-disjoint on all 2,699 samples, but their fold boundaries differ.

## 5. Discrepancy & Critical Nuance Analysis

While the artifact is a verified prompt-disjoint out-of-fold prediction, two critical structural nuances must be understood before proceeding to EXP52:

### Nuance A: Lineage Mismatch vs Nishant Dahal's Checkpoint
- **Nishant Dahal Part Two (`two-stage-lora-part-two.ipynb`)**:
  - Checkpoint: `lora_qwen3_14b` in `nishantdahal/ntl-handwriting-blend`.
  - Training Data: 83k public pool + train.
  - Reported CV: **0.611 BA** out-of-fold.
  - Checkpoints published: **Only 1 full-fit checkpoint** (no fold checkpoints).
- **Anto Pil / Dhruv Tibarewal (`antopil/ntl-oof-anto-pil`)**:
  - Checkpoint: `q14v5` in `dhruvtibarewal/nlm-l24-adapters-v5`.
  - Training Data: 120k public pool + train.
  - Verified CV: **0.6346 BA** out-of-fold.
  - Checkpoints published: **5 fold adapters (`q14v5_f0`..`f4`) + 1 full-fit (`q14v5`)**.

**Strategic Impact**: The `q14v5` model family is actually **superior** to Nishant Dahal's model (+0.0236 higher CV) and has verified 5-fold checkpoints available for reproduction.

### Nuance B: Fold Partition Mismatch vs Local Baseline EXP47
- **EXP47 (Qwen3-8B Centred Twin)**:
  - Generated using `GroupKFold(5)` on `train.csv` in file order.
  - Fold 0 contains prompts `p000`, `p001`, `p002`, `p005`...
- **Anto Pil Qwen3-14B (`q14v5`)**:
  - Generated using `RandomState(0).shuffle(prompts)` before mod 5.
  - Fold 0 contains prompts `p000`, `p003`, `p009`, `p014`...

**Consequence for Blending**:
- Across the entire dataset (all 2,699 samples), **every sample was predicted out-of-fold by both models**.
- However, because the 30-prompt holdout sets differed between the two training runs, a row $i$ in prompt $p$ was evaluated against an 8B model trained on one 120-prompt subset and a 14B model trained on a different 120-prompt subset.
- This does **not** introduce label leakage (neither model saw prompt $p$), but it means the fold-by-fold splits do not align 1-to-1.
